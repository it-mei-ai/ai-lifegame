# AI時代の失敗体験型ライフゲーム

公開URL: [https://g.it-mei.com/ai-lifegame](https://g.it-mei.com/ai-lifegame)

最新版（キャラクター冒険版）: [https://g.it-mei.com/ai-lifegame13](https://g.it-mei.com/ai-lifegame13)

## 最新リリース: Version 13

- 世界、ステージ名、問題を事前に選ぶ操作を廃止
- 5キャラクターから相棒を選ぶだけで冒険開始
- キャラクターごとに背景、世界名、5つのステージ名を自動変更
- 各キャラクター専用の固定問題を5問ずつ、合計25問収録
- PC・スマートフォン対応

Version 13のブラウザ単体版ソースは `standalone/ai-lifegame13/` にあります。`index.html`を開くだけで実行できます。

AI、SNS、怪しいURL、人間関係のトラップを安全に体験し、現実で使える確認力・相談力・倫理観を学ぶWebアプリMVPです。

## 内容

- スタート画面
- 人生ゲーム風マップ
- 5つのイベント
  - AIに頼りすぎた課題提出
  - SNSなりすましDM
  - 友人関係とSNS投稿
  - 怪しいURL
  - 報連相ミス
- 選択肢によるスコア変化
- 最終診断と振り返り
- アンケートリンク設置欄

## 起動

```bash
pnpm run dev
```

## ビルド

```bash
pnpm run build
```

## シナリオ編集

`app/LifeGame.tsx` の `events` 配列にイベントを追加・編集します。

各イベントは以下を持ちます。

- `title`: マス名
- `stage`: ライフステージ
- `type`: トラップ種別
- `scene`: 状況説明
- `prompt`: 選択前の問い
- `clues`: 見るべきサイン
- `choices`: 選択肢、フィードバック、スコア変化

## 安全設計

- 実在企業名、実URL、実電話番号は使わない
- 本物の個人情報、パスワード、カード情報は入力させない
- 詐欺やフィッシングの手口を実行可能な形で詳述しない
- 教育用シミュレーションであることを明示する
